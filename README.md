Code Empath 🤝 Your all-in-one college companion for mentorship, resources, and smart learning.

A 24-hour project built for the Lumina Hackathon! ✨

🚀 The Problem College students often feel disconnected and overwhelmed. It's hard to find the right mentors, key announcements are scattered across different platforms, and it's easy to get buried in dense lecture notes and study materials.

💡 Our Solution Code Empath is a centralized web platform designed to solve these problems. It's a single hub that helps students succeed by:

Connecting them directly with senior mentors.

Organizing all academic resources in one place.

Providing AI-powered tools to make studying more efficient.

🌟 Key Features 1-on-1 Mentorship Chat: Instantly connects students with experienced seniors for guidance, advice, and support.

Collaborative Discussion Rooms: Topic-based chat rooms for group study sessions, project collaboration, or subject-specific discussions.

Centralized Dashboard: A single source of truth for daily timetables, lecture notes, and important announcements. Faculty and seniors can easily upload resources.

Smart Summarizer: An AI tool that instantly condenses long PPTs, research papers, and PDF notes into key takeaways, saving valuable study time.
